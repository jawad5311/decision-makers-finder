# Decision Makers Finder

This Manifest V3 extension adds a floating **Find the Decision Makers** button to ordinary websites. It removes only a leading `www.` from the current hostname, appends each configured query, and URL-encodes the complete search. The first query opens in the current tab; each remaining query opens in its own new tab.

Open the extension popup to enable or disable the on-page button and provide search queries (one per line). Clicking the button opens all configured searches in separate tabs. The default query is `decision makers`.
